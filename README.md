# Coffee Sales Analysis Dashboard

## Project Overview
This Excel project analyzes coffee shop sales data to understand transaction volume, product performance, location-wise sales, and sales patterns across different days and months.

The interactive dashboard helps identify important business trends and provides a clear summary of sales performance.

## Key KPIs
•⁠  ⁠Total Quantity Sold: 214,470
•⁠  ⁠Total Transactions: 149,116

## Dashboard Analysis
The dashboard includes:
•⁠  ⁠Top 10 Products by Quantity Sold
•⁠  ⁠Location-wise Sales
•⁠  ⁠Product-wise Sales
•⁠  ⁠Distribution by Product Type
•⁠  ⁠Sales trend analysis
•⁠  ⁠Day-wise filtering
•⁠  ⁠Month-wise filtering
